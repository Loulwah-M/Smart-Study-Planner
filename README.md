# Smart-Study-Planner
## Project Description
A student study planner to organize university courses, assignments, deadlines, and study schedules, with planned integration with Microsoft Teams.

## Team Members
- Loulwah Alsahali
- Malak Alenezi
- Rifal Meshari Alkhudhair

## Main Features
- Manage courses, assignments, and exams.
- View upcoming deadlines in one dashboard.
- Generate a weekly study schedule.
- Track completed tasks and study progress.
- Receive reminders for upcoming deadlines.
- Update the study plan when deadlines change.
